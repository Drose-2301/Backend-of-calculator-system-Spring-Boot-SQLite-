# Front-End and Back-End Separated Calculator System — Backend

## Project Overview

This is the backend of a front-end / back-end separated calculator system. It is responsible for receiving calculation requests, parsing mathematical expressions, performing calculations, handling exceptions, and persisting calculation history to the database.

## Tech Stack

- Java 17
- Spring Boot 3.4
- Spring Data JPA
- SQLite
- Hibernate
- Maven (using the project's bundled mvnw)

## Runtime Environment

- JDK 17 or later
- No need to install Maven separately; the project includes Maven Wrapper

## Installation and Startup

Run from the project root directory:

**Windows:**
\`\`\`bash
.\mvnw.cmd spring-boot:run
\`\`\`

**macOS / Linux:**
\`\`\`bash
./mvnw spring-boot:run
\`\`\`

After starting, the backend listens on `http://localhost:8080`.

## Database

- Uses SQLite — **no database service installation required**
- On first startup, a `calculator.db` file is automatically created in the project root
- The table `calculation_history` is automatically generated by Hibernate

Table structure:

| Field | Type | Description |
|-------|------|-------------|
| id | INTEGER | Primary key, auto-increment |
| expression | VARCHAR(255) | Calculation expression |
| result | FLOAT | Calculation result |
| created_at | TIMESTAMP | Calculation time |

## API

| Method | Path | Description |
|--------|------|-------------|
| POST | /api/calculate | Calculate an expression |
| GET | /api/history | Get all history records |
| DELETE | /api/history/{id} | Delete one record |
| DELETE | /api/history | Clear all records |

### Request Example

\`\`\`json
POST /api/calculate
{ "expression": "(1+2)*3" }
\`\`\`

### Response Example

Success:
\`\`\`json
{ "success": true, "expression": "(1+2)*3", "result": 9, "message": null }
\`\`\`

Failure:
\`\`\`json
{ "success": false, "expression": "10/0", "result": null, "message": "Division by zero is not allowed" }
\`\`\`

## CORS Configuration

The backend is configured to allow requests from `http://localhost:5173` and `http://localhost:5174`. See `config/CorsConfig.java`.

## Expression Parsing

The backend **does not use eval / exec or any arbitrary code execution methods**. It uses a hand-written recursive descent parser (`service/ExpressionParser.java`) that supports:

- Addition, subtraction, multiplication, division
- Parentheses
- Operator precedence
- Unary plus and minus
- Decimal numbers
- Division by zero detection
- Invalid character detection
- Parenthesis matching detection
